# Emil Ağalarov | İngilis Dili Tədris və Tələbə İdarəetmə Portalı 🎓

Müasir, tam responsiv, istehsala hazır (production-ready) EdTech və Tələbə İdarəetmə Veb Tətbiqi.
Bu layihə peşəkar ingilis dili müəllimi **Emil Ağalarov** üçün xüsusi olaraq hazırlanmışdır.

## 🌟 Əsas Funksiyalar və Bölmələr

### 1. Müəllim İdarəetmə Paneli (Admin / Emil Ağalarov)
- **İcmal Kartları (Overview KPIs):**
  - Aktiv tələbələrin sayı və qrup bölgüsü (A1, A2, B1, B2).
  - Aylıq təhsil haqqı balansı (Toplanan məbləğ, gözlənilən qalıq və faiz).
  - Tələbələrin orta sınaq balı və ümumi inkişaf dinamikası.
  - Cari davamiyyət göstəricisi və dərs iştirak nisbəti.
- **Tələbələrin İdarə Edilməsi (Student Management CRUD):**
  - Tələbə əlavə etmə, redaktə etmə və silmə.
  - Səviyyə/Qrup təyini (A1, A2, B1, B2, IELTS).
  - Valideyn telefon nömrəsi və aylıq ödəniş məbləği.
  - Hər tələbə üçün unikal 8 simvollu giriş kodu (məs: `MURA-2026`). 1-kliklə kopyalama imkanı.
- **Davamiyyət Jurnalı (Attendance Tracker):**
  - Dərs tarixi, qrup seçimi və dərs mövzusunun qeydi.
  - Çevik status seçimi: *İştirak edib (Present)*, *Gəlməyib (Absent)*, *Gecikib (Late)*, *İcazəli (Excused)*.
  - "Hamısını İştirak Edib İşarələ" sürətli düyməsi və qeyd sahəsi.
- **Sınaq və Mock Nəticələri (Exam & Mock Results):**
  - Bölmələr üzrə bal daxiletmə: *Reading (25)*, *Listening (25)*, *Grammar (25)*, *Vocabulary (25)*.
  - 100 ballıq ümumi nəticənin avtomatik hesablanması.
  - Müəllim rəyi və tövsiyələri (Azərbaycan dilində fərdi qeydlər).
- **Ödəniş Nəzarəti (Tuition Tracker):**
  - Tələbələrin aylıq ödəniş cədvəli (Ödənilib - Yaşıl, Gözlənilir - Qırmızı).
  - 1-kliklə status dəyişmə (Ödənildi / Gözlənilir).
  - Toplam toplanan məbləğ və qalıq hesabatı.
- **Dərs Vəsaitləri və Quiz İdarəetməsi (Content Manager):**
  - YouTube video dərslərinin kateqoriyalara (Tenses, Modal Verbs, Vocabulary, Listening) və səviyyələrə görə əlavə olunması.
  - Çoxseçimli interaktiv testlərin (Quiz) yaradılması (Sual, 4 variant, düzgün cavab indeksi və Azərbaycan dilində qrammatik izah).
- **Ev Tapşırıqları İdarəetməsi (Homework):**
  - Qruplar üzrə tapşırıqların təyini, son təhvil tarixi və yüklənə bilən vəsaitlər.

## 🚀 Texnoloji Yığın (Tech Stack)

- **Frontend:** React 18, TypeScript, Vite.
- **UI & Stillər:** Tailwind CSS (Zərif tünd göy, zümrüd yaşılı vurğular, müasir kartlar).
- **İkonlar:** Lucide Icons.
- **Qrafiklər:** Recharts (Tələbə irəliləyiş qrafiki).
- **Animasiyalar:** Canvas Confetti.
- **Verilənlər Bazası Təbəqəsi:** Modular Service Layer (`src/services/db.ts`). İlkin olaraq `localStorage` ilə avtomatik sinxronlaşır. İstənilən vaxt bir toxunuşla canlı **Supabase** və ya **Firebase** ilə əvəzlənə bilər.

## 📦 Layihəni Lokal İşə Salmaq (Local Run)

1. **Repozitoriyaya daxil olun:**
   ```bash
   cd /Users/agalarzade/.gemini/antigravity/scratch/emil-agalarov-edtech
   ```

2. **Node mühitini təmin edin və asılılıqları quraşdırın (artıq quraşdırılıb):**
   ```bash
   npm install
   ```

3. **İnkişaf serverini başladın (Development Server):**
   ```bash
   npm run dev
   ```
   Brauzerdə `http://localhost:3000` ünvanını açın.

4. **Production Build yaratmaq:**
   ```bash
   npm run build
   ```

## 🗄️ Canlı Verilənlər Bazasının Qoşulması (Supabase / Firebase)

Tətbiq `src/services/db.ts` daxilində tam mücərrəd və asinxron API ilə yazılmışdır.
Canlı məlumat bazasını qoşmaq üçün:

### Variant A: Supabase Qoşulması
1. `.env.example` faylını `.env` kimi kopyalayın:
   ```bash
   cp .env.example .env
   ```
2. `VITE_SUPABASE_URL` və `VITE_SUPABASE_ANON_KEY` məlumatlarını qeyd edin.
3. `src/services/supabaseClient.ts` faylındakı müvafiq metodları aktiv edin.

### Variant B: Firebase Qoşulması
1. `.env` daxilində `VITE_FIREBASE_API_KEY` və digər parametrləri qeyd edin.
2. `src/services/firebaseConfig.ts` faylındakı konfiqurasiyanı aktivləşdirin.
